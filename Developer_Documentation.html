1. Project Overview

Jan Industries is a dairy-equipment manufacturer and spare-parts supplier based on GT Road, Lahore, Pakistan. The website serves as a digital catalog for milking machines and genuine replacement parts, with direct WhatsApp ordering integration for farmers across Pakistan.

Design Philosophy: Industrial-minimal. Crisp 1px borders, real shadows, warm off-white background, slate typography, and amber accent. Intentionally avoids AI-template aesthetics — no glassmorphism, no generic gradients, no over-rounded pills.

Key Features:

  • Hero section with interactive product hotspots
  • Animated scroll-reveal on all sections
  • Count-up statistics counter
  • Product category filtering (machines, pumps, liners, cleaning)
  • FAQ accordion
  • Testimonial carousel grid
  • Floating WhatsApp action button
  • Mobile bottom action dock
  • Sticky header with scroll effects
  • Urdu language support in hero section

7.3 Product Cards (.product-card)

  • Structure: .product-media → .product-content
  • Image uses aspect-ratio: 1/1 with object-fit: cover
  • Hover: lifts 4px, increases shadow, scales image 5%
  • Badge positioned absolutely at top-right
  • CTA button spans full width of card

7.4 Hero Hotspots (.hotspot-btn)

  • Absolute-positioned overlay buttons on hero image
  • Pulse animation ring + glowing dot
  • Click triggers category filter and scrolls to product card
  • Label tooltip appears on hover
  • Hidden on mobile; replaced by .mobile-hotspot-pill list

7.5 Section Headers (.section-header)

<div class="section-header">

  <h2 class="section-title">Section Title</h2>
  <p class="section-desc">Description text.</p>
</div>

8. JavaScript Modules

All JavaScript lives in script.js — zero dependencies, vanilla ES6+. Initialized on DOMContentLoaded.

initProductCatalog()Category tab filtering with fade/slide animation, keyboard nav (arrow keys)Tab click
initHeroHotspots()Hotspot buttons filter category + scroll to product; highlight pulseHotspot click
initStatsCounter()Animated count-up when stats section enters viewport (IntersectionObserver)Scroll into view
initFaqAccordion()FAQ accordion with smooth max-height animation, single-open at a timeQuestion click
initScrollReveal()Fade + slide-up reveal on elements with .reveal classScroll into view

Global Exposure: window.janSetCategory is exposed for hotspot-to-category integration.

8.1 Reduced Motion Support

All animations respect @media (prefers-reduced-motion: reduce). Transitions are disabled, reveals are instant, and hover transforms are removed.

11. Accessibility (a11y)

  • Skip-to-content link (.skip-link) for keyboard users
  • Semantic HTML5: <header>, <main>, <section>, <footer>, <article>, <figure>
  • ARIA labels on all interactive buttons and nav
  • aria-expanded on accordion and mobile menu
  • role="tablist", role="tab", role="tabpanel" on category tabs
  • Focus-visible outlines on all focusable elements
  • Language attributes: lang="ur" dir="rtl" on Urdu content
  • Schema.org LocalBusiness structured data
  • Open Graph meta tags for social sharing
  • Reduced motion media query support
  • Alt text on all product images

13. Deployment Guide

Static Site: This is a pure static site. No build step, no server, no database required.

13.1 Deployment Options

  • GitHub Pages: Push to gh-pages branch or enable Pages from main branch
  • Netlify / Vercel: Drag-and-drop the folder or connect Git repo
  • Traditional Hosting: Upload via FTP/cPanel to public_html
  • Local Testing: Open index.html directly, or use python -m http.server / npx serve

13.2 Pre-Deployment Checklist

  • Verify all image paths are correct (images/ folder present)
  • Confirm favicon.svg exists in root
  • Test WhatsApp links with correct phone numbers
  • Update Schema.org phone numbers and address if changed
  • Update copyright year in footer
  • Run Lighthouse audit for performance/accessibility

14. Maintenance & Updates

14.1 Adding a New Product

  1. Add product image to images/ folder
  2. Copy an existing <article class="product-card"> block in index.html
  3. Update id, data-category, image src, title, specs, and WhatsApp link
  4. Add corresponding category tab button if new category
  5. Update "All Products (X)" count in the All tab

14.2 Changing Colors

Edit CSS custom properties in the :root block at the top of style.css. No component-level changes needed.

14.3 Adding a New Section

  1. Add <section> block in index.html with id and class="reveal"
  2. Add styles in style.css following existing section patterns
  3. Add navigation link in header and footer if needed
  4. Add corresponding entry in initScrollReveal (automatic via .reveal class)

14.4 Image Optimization

  • Use JPEG for product photos, WebP preferred
  • Keep hero images under 200KB
  • Use loading="lazy" for below-fold images, loading="eager" for hero
  • Always include width and height attributes to prevent layout shift
